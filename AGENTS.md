# ExpoKit — notes for AI agents

ExpoKit is a shadcn-style kit for Expo / React Native: the CLI copies component source into apps.

## Layout

- `registry/<kind>/<name>/` — one item: `item.json` (meta, props), `src/**` (what the CLI copies), `demo.tsx` (preview variants).
- `registry/lib/kit` — the shared theme (`useKit`, `KitProvider`, `motion`, `alpha`). Every component depends on it.
- `packages/cli` — `@anshkaran7/expo-kit`. `packages/cli/registry/` is generated by the maintainer's build; don't edit it by hand.
- `packages/charts` — `expo-charts`.

## Rules for components

Read `registry/CONTRIBUTING.md` first. In short: plain React Native `Animated` + `react-native-svg` (no Reanimated, Skia or
Gesture Handler), theme from `useKit()` (never hard-coded colours), native driver for transform/opacity, springs for touch,
controlled + uncontrolled props, accessibility roles and 44pt targets, works on iOS, Android, web and Expo Go.

## Checks

```bash
npm ci
npm test            # CLI tests
npm run typecheck   # every free component and demo
```

Pro items are not in this repository — don't recreate them here. This repo is a read-only mirror (PRs are closed automatically); suggest changes in an issue.
