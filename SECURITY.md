# Security

Please don't report security problems in public issues.

Report them privately through https://expokit.karandev.in/support with "Security" in the subject — what you found, how to
reproduce it and what it affects (a component, the CLI, `expo-kit login` / tokens, or the website). You'll get a reply
within a few days, and a fix and credit (if you'd like it) once it is released.

Supported: the latest published version of `@anshkaran7/expo-kit` and `expo-charts`, and the components in `registry/`
on `main`.
